# AML 요주의 인물/법인 WLF 자동 검증 PoC

**품의서 텍스트 → 업체명·대표자명 추출 → 요주의 리스트(WL) 대조 → 위험건 알림** 흐름이
끝까지 동작하는 1일 교육용 PoC입니다. 모든 데이터는 가상이며 실제 AML 시스템과 연동하지 않습니다.

## 빠른 실행

```bash
pip install -r requirements.txt

streamlit run app.py      # 화면 데모: 품의서 업로드 → 추출 결과 → 매칭 결과표 → 알림
python cli.py             # 터미널 데모 (data/drafts/*.txt 전체 검증, 표준 라이브러리만 사용)
python -m unittest        # 테스트 케이스표 자동 검증
```

`ANTHROPIC_API_KEY` 가 설정돼 있으면 화면의 **AI(Claude) 추출 사용** 토글(또는 `python cli.py --ai`)로
Claude 추출을 쓸 수 있습니다. 키가 없거나 호출이 실패하면 정규식 추출로 자동 대체되므로
교육장에서 API 키를 쓸 수 없어도 PoC는 그대로 동작합니다.

## 업무 규칙 (구현 기준)

- **추출**: 본문의 `계약업체`, `대표자` 항목에서 이름을 뽑음. `대표자 : 홍길동 (1980-07-15)` 처럼 괄호 안 생년월일도 함께 추출. `설립일`, `국가` 항목이 있으면 동명이인 구분에 사용.
- **정규화**: 공백·특수문자 제거, 법인 표기 제거(한글 표기 + 단어 경계의 Co.,Ltd / Inc / Corp / LLC 등), 영문 대문자 통일.
- **매칭 대상**: 업체명 ↔ WL `법인`, 대표자명 ↔ WL `개인`. 각 WL 행의 `name_kr`, `name_en`, `alias`(쉼표 구분) 전부와 비교해 가장 높은 점수를 사용.
- **점수**: 정규화 후 완전 일치 100점, 그 외 Jaro-Winkler × 100 (한글은 음절 단위).
- **가감점** (한 번만 적용, 0~100으로 자름):
  1. 품의서와 WL 양쪽에 생년월일/설립일이 있으면 일치 +5, 불일치 −10
  2. 날짜가 없으면 국가를 비교해 일치 +5, 불일치 −10
  3. 둘 다 비교할 수 없으면 0
- **판정**: 95점 이상 확정 Hit / 85~94점 의심 / 85점 미만 정상 (`wlf/matcher.py` 상단 상수로 조정)
- **알림**: 업체명·대표자명 중 하나라도 Hit/의심이면 알림. 위험등급 `상` → `중` → `하` 순으로 최상단 표시, 같은 등급 안에서는 Hit → 의심, 점수 내림차순.

## 데모 시나리오 (5분)

1. `① 품의서 검증` 탭에서 샘플 8건 선택 → **검증 실행**
2. 상단 **알림**: 위험등급 `상` 건이 맨 위, Hit는 빨강·의심은 주황
3. **추출 결과 확인** 표로 AI/정규식 추출값 확인
4. **매칭 결과표**에서 이름점수 → 가감점(사유) → 최종점수 → 판정 근거 설명
5. `② 요주의 리스트 조회`에서 `GND`·`Dawn` 검색 (모의 연동)
6. `③ 검증 이력`에서 위험건 **담당자 확인** 체크 → **확인 완료 저장**

## 데이터 원칙과 향후 과제

- 모든 이름·사업자번호(`000-00-0000x`)·생년월일은 가상값입니다. 실존 인물·기업을 넣지 마세요.
- 실제 AML 시스템 화면 캡처는 쓰지 않고, 화면은 "검색창 + 결과표 + 알림" 구조만 구현했습니다.
- 추후 실제 연동 대상(발표 자료용): OFAC SDN, UN 안보리 제재 리스트, 금융위 금융거래제한대상자 고시, 사내 AML 시스템 API
- 미구현(Nice-to-have 잔여): PDF 품의서 업로드, 영문↔한글 이름 음역 매칭
